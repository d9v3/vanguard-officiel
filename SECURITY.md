# Security

This repository only holds Vanguard's signed releases, used by its updater. The code and the full security policy live
in [d9v3/vanguard-beta](https://github.com/d9v3/vanguard-beta/blob/master/SECURITY.md).

Report a vulnerability in Vanguard, its signing or its updates **privately**, never in a public issue: **Security**
tab, **Report a vulnerability** button, on this repository or, preferably, on
[vanguard-beta](https://github.com/d9v3/vanguard-beta/security/advisories/new). What to include, response times and
disclosure: see the full policy.
